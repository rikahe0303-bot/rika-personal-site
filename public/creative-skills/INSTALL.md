# Codex 创作技能合集

7 项独立编写的 Codex 本地适配版。功能方向参考 https://vibepaper-ai.com/skills ，非 VibePaper 官方导出包。

1. 解压 ZIP，找到每个 `rika-...` 文件夹。
2. 将需要的文件夹复制到 `~/.codex/skills/`。保留其中的 `SKILL.md`、`agents/`、`references/`。已有同名目录时先备份再决定是否替换。
3. 在下一条 Codex 消息里通过 `$rika-camera-direction` 等名称调用；列表没有刷新时重开 Codex。

只写文案、分镜和提示词不需要 VibePaper 账号；实际生图、生成式视频或外部服务需要相应工具、权限及可能的费用。本包不附带模型权重、访问凭据或生成额度。

本公开分享包将 Rika 本机专用参考路径改为随包携带的便携规则，避免其他电脑缺少对应目录。当前用户要求和项目规则优先。
