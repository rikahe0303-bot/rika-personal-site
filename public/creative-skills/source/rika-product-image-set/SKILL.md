# 电商商品套图视觉生成

根据 [VibePaper Skill 广场](https://vibepaper-ai.com/skills)公开功能说明，为 Rika 独立编写的 Codex 本地适配版。不是 VibePaper 官方导出包，未取得平台隐藏指令；不依赖 VibePaper 登录或积分来撰写方案和提示词。

## 工作流程

1. 查看商品参考图，记录外形、比例、颜色、包装字样、商标、配件、数量和不可改变的识别特征。确认目标用途与已知画幅；平台规格不确定且影响交付时查官方要求。
2. 为每张图确定独立的信息任务，例如商品识别、使用场景、材质细节、真实卖点或已知规格。数量服从用户需求，不通过重复构图凑套数。
3. 建立统一配色、背景、光向、投影、景别和文字层级。主图优先展示商品本体；场景图让用途清楚，细节图必须对应真实结构，尺寸图仅使用已确认数值。
4. 先输出精简图片清单与每图提示词，用户要求生成时直接用可用图片工具制作。每张绑定同一商品参考，锁定商标、形状、颜色、配件和数量；只有用户要求时才改变包装或产品设计。
5. 图片中文字若无法准确生成，将底图与排版分开处理；逐字核对型号、参数、价格和标签。需要透明底时确认真实透明通道，按目标渠道输出所需尺寸与格式。

## 验收

逐图检查商品是否变形、商标错字、配件缺失、材质或色彩偏差、虚构功能、比例失真以及套图一致性。交付实际图片及用途清单；只完成方案时明确图片尚未生成。不主动上传电商平台或发布商品。
