# 真人 Vlog 短片生成

根据 [VibePaper Skill 广场](https://vibepaper-ai.com/skills)公开功能说明，为 Rika 独立编写的 Codex 本地适配版。不是 VibePaper 官方导出包，未取得平台隐藏指令；不依赖 VibePaper 登录或积分来撰写方案和提示词。

## 工作流程

1. 识别人物参考、拍摄地点、时间、情绪和素材权限。用户有本人素材时保持面部身份、衣着及关键物品，选择第一人称或第三人称的观看关系。
2. 围绕一个日常事件安排发生、互动和余韵，镜头数量服从内容和时长。已有录像先找可用动作与原声，再补缺失镜头。
3. 用具体自然光、镜头距离、动作和环境声表达真实感。手持运动轻微且有动机；失焦和曝光变化仅在合适时少量使用，不能以故意低画质代替生活感。
4. 一镜写清人物做什么、与何物互动、摄影机如何跟随及何时停。接触、拿取、脚步和视线要有合理顺序；同一物件和人物跨镜保持一致。
5. 逐镜给出时间｜画面与动作｜视角和运动｜自然光｜原声/环境声｜人物与物品锁定｜生成提示词。默认保留自然表情与皮肤质感；无要求时不把人物商业精修化。

## 检查重点

核对脸、手和互动接触；检查背景物品漂移、重复路人、突变曝光和突兀手持抖动。剪辑保留真实动作与情绪停顿；不自动改变用户原声或伪造实拍来源。

## 视频制作参考

实际视频任务先读取随包附带的 [Rika 视频规则](references/rika-video-rules.md)，再按当前用户要求与本机工具实施。若本机已安装 `rika-video-workflow` 或 `mg-styles-15`，可以衔接相应技能；未安装时依照本文件与当前可用工具继续，不将参考技能当作硬性依赖。

## 实际执行与交付

按用户请求交付方案、提示词、素材或成片。制作图片时使用当前可用的图片编辑或生图工具；已有实拍素材优先用剪辑或 Remotion 工作流。生成模型负责人物真实动作，代码动效不能冒充生成式人物表演。调用外部服务前确认可用性与计费条件；缺少视频生成能力时交付可执行分镜和提示词，明确成片尚未生成。最终检查实际产物，区分设计方案、已生成素材和已验证成片。
