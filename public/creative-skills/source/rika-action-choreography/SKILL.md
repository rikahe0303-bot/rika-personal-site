# 高燃打戏设计

根据 [VibePaper Skill 广场](https://vibepaper-ai.com/skills)公开功能说明，为 Rika 独立编写的 Codex 本地适配版。不是 VibePaper 官方导出包，未取得平台隐藏指令；不依赖 VibePaper 登录或积分来撰写方案和提示词。

## 工作流程

1. 依据剧情明确双方目标、能力差异、情绪和结局，建立场地平面关系、障碍物、道具及退路。区分写实、武侠和超自然规则。
2. 将动作按试探、压力升级、局势变化和收束安排，按实际时长合并或扩展。每段保留一个观众能看懂的动作目的。
3. 用“意图 → 动作 → 对方反应 → 位置变化”组织节拍。镜头突出表演与叙事，不给现实攻击要害、武器使用或致伤操作教程。
4. 为每个节拍写清谁从哪里移动到哪里、观众从何角度看到结果；保持轴线、方向、道具持握和损伤连续性。先用清楚全景建立地理关系，再用近景强调反应。
5. 特效对应已建立的世界规则，写清起点、路径、颜色和消散。尘土、衣物、道具和环境反馈要与动作时序一致，不靠强闪和乱切掩盖不连贯。
6. 交付动作节拍表和镜头表：时间｜剧情任务｜人物起终位置｜动作及反应｜景别/运镜｜环境反馈｜声音｜连续性约束；逐镜给生成提示词与失败检查点。

## 预演与验收

优先做关键动作段落预演，检查主次人物和空间方向；减少超出模型可控范围的一镜多动作。真人素材涉及危险表演时采用已有合规素材、动画或专业替身预演，不要求用户实施危险动作。

## 视频制作参考

实际视频任务先读取随包附带的 [Rika 视频规则](references/rika-video-rules.md)，再按当前用户要求与本机工具实施。若本机已安装 `rika-video-workflow` 或 `mg-styles-15`，可以衔接相应技能；未安装时依照本文件与当前可用工具继续，不将参考技能当作硬性依赖。

## 实际执行与交付

按用户请求交付方案、提示词、素材或成片。制作图片时使用当前可用的图片编辑或生图工具；已有实拍素材优先用剪辑或 Remotion 工作流。生成模型负责人物真实动作，代码动效不能冒充生成式人物表演。调用外部服务前确认可用性与计费条件；缺少视频生成能力时交付可执行分镜和提示词，明确成片尚未生成。最终检查实际产物，区分设计方案、已生成素材和已验证成片。
